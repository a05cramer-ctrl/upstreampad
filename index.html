Fees flow upstream.

Every GitHub repo gets its own vault. Coins launched on it send their pump.fun creator fees there, and the repo’s maintainer claims them by signing in with GitHub.

How it works

Three steps. Real numbers.

  1. 01

    Pick any public repo

    repo → vault

    Its numeric GitHub id, which survives renames, derives a dedicated Solana vault. Same repo, same vault, every time.

  2. 02

    Launch on pump.fun

    0.01 SOL

    You pay and sign. The vault is set as the coin’s creator, so pump.fun’s creator fee, 0.30% of every bonding-curve trade and 0.05–0.95% after graduation to PumpSwap depending on market cap, accrues to the repo.

  3. 03

    The maintainer claims

    GitHub admin

    Sign in with GitHub. If you’re an admin of the repo, the vault’s pump.fun and PumpSwap fees are collected and sent to any wallet you name. No admin rights, no claim.
